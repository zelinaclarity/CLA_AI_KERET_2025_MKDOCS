# MkDocs konfiguráció (mkdocs.yml)

A dokumentáció struktúráját és navigációját a projekt gyökerében
található `mkdocs.yml` fájl határozza meg.

Ez a fájl vezérli: - a dokumentáció menüjét, - a theme beállításokat, -
a pluginokat, - a Markdown kiterjesztéseket, - az oldalak hierarchiáját.

------------------------------------------------------------------------

## Navigáció (nav)

A bal oldali menü tartalmát a `nav` szekció határozza meg.

Példa:

``` yaml
nav:
  - Kezdőlap: index.md

  - Fejlesztői:
      - Áttekintés: developer/index.md
      - Dokumentáció használata: developer/documentation.md
      - Autogenerated:
          - Services: _generated/services/index.md
          - Traefik routing: _generated/traefik/routing.md
          - Config:
              - Env vars: _generated/config/env-vars.md
              - Secrets: _generated/config/secrets.md
              - Volumes: _generated/config/volumes.md

  - Telepítés és üzemeltetés:
      - Áttekintés: ops/index.md

  - Felhasználói:
      - Áttekintés: user/index.md
```

Fontos: a fájlútvonalak a `docs/` könyvtárhoz képest értendők.

Példa:

-   fájl a repóban: `docs/developer/documentation.md`
-   hivatkozás a `mkdocs.yml`-ben: `developer/documentation.md`

------------------------------------------------------------------------

## Új oldal hozzáadása

Új dokumentációs oldal hozzáadásához:

1.  Hozd létre a Markdown fájlt a `docs/` könyvtárban.
2.  Add hozzá a megfelelő helyen a `mkdocs.yml` `nav` szekciójához.

Példa:

``` yaml
- Fejlesztői:
    - Új komponens: developer/new_component.md
```

Mentés után a változás normál esetben automatikusan megjelenik a
dokumentációban.

------------------------------------------------------------------------

## Autogenerált oldalak a navigációban

Az automatikusan generált dokumentáció a következő könyvtárban
található:

-   `docs/_generated/`

Ezeket a fájlokat kézzel nem szerkesztjük, generáláskor felülíródnak.

Ha új generált dokumentum kerül ide, akkor: - vagy automatikusan bekerül
egy index oldalon keresztül (pl. `services/index.md`), - vagy manuálisan
hozzáadható a `nav` szekcióhoz.

------------------------------------------------------------------------

## Változások frissítése

Ha a `mkdocs.yml` módosul, a dokumentáció szervernek újra kell építenie
az oldalt.

Normál esetben ez automatikus.

Ha nem frissül: - böngészőben: `Ctrl + F5` - vagy konténer restart:

``` bash
docker compose -f docker-compose.yml -f docker-compose.docs.yml restart docs
```

------------------------------------------------------------------------

## Gyakori hibák

### Az oldal nem jelenik meg a menüben

Ok: - nincs hozzáadva a `nav` szekcióhoz.

Megoldás: - add hozzá a `mkdocs.yml`-hez a megfelelő helyen.

### Hibás útvonal

Ha a fájl útvonala nem egyezik a `docs/` struktúrával, az oldal nem fog
betöltődni.

Példa:

-   fájl: `docs/developer/example.md`
-   helyes hivatkozás: `developer/example.md`

------------------------------------------------------------------------

## Javasolt gyakorlat

-   A `mkdocs.yml` módosítását mindig commitoljuk.
-   Új dokumentációs fájl esetén a navigációt is frissítsük.
-   A dokumentáció szerkezetét tartsuk konzisztensen a három fő
    kategória szerint:
    -   `developer`
    -   `ops`
    -   `user`
