# Framework komponensek

Ez a fejezet a framework compose-ban szereplő komponensek fejlesztői nézetű leírásait tartalmazza.

## Cél

A komponensoldalak célja, hogy egy helyen összefoglalják:

- az adott service szerepét,
- a fő függőségeit,
- a fontos portokat,
- a mountolt konfigurációs és adatfájlokat,
- a fejlesztés szempontjából lényeges megjegyzéseket.

## Megjegyzés

Ezek az oldalak első körös, részben automatikusan előállított vázak a rendelkezésre álló `docker-compose.yml` alapján. Később kézzel érdemes kiegészíteni őket:

- belső működési leírással,
- kapcsolódó forrásfájlok részletezésével,
- fejlesztési döntésekkel,
- tipikus hibákkal és workaroundokkal.
