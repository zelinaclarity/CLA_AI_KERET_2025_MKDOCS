# Traefik

## Cél

A `traefik` a framework reverse proxy és ingress komponense. TLS végpontokat kezel, Docker providerből és file providerből dolgozik, és több UI / API komponenst publikál domain alapú routinggal.

## Compose szerep

- image: `traefik:v3.6.7`
- container_name: `traefik`
- restart: `unless-stopped`

## Portok

- `80:80`
- `443:443`

## Fő konfiguráció

### Command paraméterek
- Docker provider engedélyezve
- `exposedbydefault=false`
- file provider: `/certs`
- entrypointok:
  - `web`
  - `websecure`
- TLS engedélyezve a `websecure` entrypointon
- log level: `INFO`

### Mountok
- `/var/run/docker.sock:/var/run/docker.sock:ro`
- `./certs:/certs:ro`

## Routing

A compose alapján legalább a következő route-ok kapcsolódnak hozzá:
- Traefik dashboard
- Dex
- OpenWebUI
- PWM
- LiteLLM OAuth2 Proxy
- API Gateway
- Grafana
